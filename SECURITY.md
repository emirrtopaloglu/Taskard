## Reporting a Vulnerability

The Taskard team takes the security of developer workflows and AI execution environments seriously. If you discover a security vulnerability (such as unintended command execution, insecure default permissions, or credential leakage), please report it responsibly.

### How to Report

1. **GitHub Security Advisory (Preferred):** Open a private report under the repository's [Security Advisories](https://github.com/emirrtopaloglu/Taskard/security/advisories) tab.
2. **Direct Email:** Alternatively, send an encrypted or direct email to [emir@topaloglu.dev](mailto:emir@topaloglu.dev) with the subject line `[SECURITY] Taskard Vulnerability Report`.

Please include:
- A description of the vulnerability and its potential impact.
- Clear step-by-step instructions to reproduce the issue.
- The operating system, CLI harness, and Taskard version used.
- Any suggested mitigations or patches if available.

### Response Timeline

- **Initial Acknowledgment:** Within 48 hours of receipt.
- **Triage & Status Update:** Within 5 business days.
- **Fix & Disclosure:** Coordinated release and disclosure schedule once the fix is verified.

Please do not disclose security vulnerabilities publicly in issues or pull requests until a fix has been officially released.
